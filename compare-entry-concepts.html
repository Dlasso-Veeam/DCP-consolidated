Compare-mode entry — concept review

Two directions for making the “enter comparison” affordance more visible and giving the as-of bar a reason to exist. Each is shown in context (the bar sitting above a mini inventory table), in both its resting and active states. Click the controls to try them.

Note: this is a layout/affordance mockup — fonts fall back to system UI (the real prototype embeds Circular Pro). Colors, spacing, radii, and icons all use the Securiti tokens.

Option A — Discovery callout strip

The empty bar becomes a tinted info strip (blue-10, the DS info-card treatment) with a solid-blue icon tile, a one-line value prop, and an outline CTA. Eye-catching via tint + icon + copy, not a competing solid-blue button. Collapses into the existing two-chip compare chrome on activation.

Option C — One-line callout strip

Option A trimmed to a single line (icon + label + CTA, no value-prop subline). Keeps the tinted anchor so it doesn't float, but reads as a control bar rather than a promo — lower vertical weight and less “marketing.”

Option D — Hybrid: discovery strip → quiet button

Full strip for first-time discovery; dismiss the ✕ and it collapses to today's quiet button for the rest of the session. New users get discovery, veterans get the unobtrusive control back. (In product the dismissed state would persist per user.) Try the ✕, then the collapsed button.
